## Background

<p>기존 북마크 시스템은 다음과 같은 구조적 문제를 가지고 있습니다.</p>

<ol class="list-decimal pl-5 space-y-3">
  <li>
    <strong>기억 문제</strong>
    <p class="ml-4">
      제목과 URL 중심의 목록형 UI로는 
      <strong>이 북마크가 어떤 내용이었는지</strong> 한눈에 파악하기 어렵습니다.
    </p>
  </li>

  <li>
    <strong>방치 문제 (링크 무덤)</strong>
    <p class="ml-4">
      저장 이후 관리 기능이 부족해 오래된 북마크는 잊히거나,
      링크가 죽어도 알 수 없습니다.
    </p>
  </li>

  <li>
    <strong>검색 비효율성</strong>
    <p class="ml-4">
      북마크를 저장해두고도 원하는 정보를 찾지 못해
      다시 검색하는 비효율이 반복됩니다.
    </p>
  </li>
</ol>

<p class="mt-4">
  SmartMark는 이 세 가지 문제를 각각 기능적으로 분리해 해결합니다.
</p>
